- 验收中未出现测试失败、HTTP 500、控制台 error 或页面横向溢出。

- 组合视图只读；未在真实数据上执行批量迁移、批量归档或恢复，避免污染用户台账。归档/恢复路径由临时目录的 175 项测试与 panel HTTP 测试覆盖。
- 归档不是删除；不验证物理清理、压缩或跨设备同步。
- `attention` 是操作提示，不是学术质量评分，也不替代 release 闸门。
